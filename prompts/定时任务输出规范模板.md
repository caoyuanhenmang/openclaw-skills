# 定时任务输出规范模板

> 适用于所有 Agent 的定时任务 Prompt 开头

---

## 📋 标准模板

```
【重要】只输出最终结果，不要输出执行步骤、思考过程、内心独白、英文日志。
输出格式：✅ + 简洁的结果摘要
```

---

## 🔧 使用方法

将上述模板添加到定时任务 Prompt 的**第一行**即可。

---

## ✅ 示例对比

### 修复前（❌ 违规）

```
Now let me read the existing memory files...
Now I have all the context. Let me create today's daily...
Now update MEMORY.md with curated key information...
✅ 已完成今日记忆整理
```

### 修复后（✅ 合规）

```
【重要】只输出最终结果，不要输出执行步骤、思考过程、内心独白、英文日志。
输出格式：✅ + 简洁的结果摘要

✅ 已完成今日记忆整理
- 提取待办：3条
- 更新索引：完成
- 通知高老师：已私信
```

---

## 📝 常见违规输出（需避免）

| 类型 | 违规示例 |
|------|---------|
| 执行步骤 | `Now let me read the existing memory files...` |
| 思考过程 | `Now I have all the context. Let me create...` |
| 内心独白 | `Now update MEMORY.md with curated key information...` |
| 英文日志 | `Processing... Done. Saving... Complete.` |

---

## 🎯 输出原则

1. **简洁**：一句话说明结果
2. **结构化**：用列表展示要点
3. **可执行**：包含明确的后续动作
4. **中文**：所有输出使用中文
