# 产品开发SOP（六阶段）

综合《快消品产品开发方法》《爆品法则》《我在小米做爆品》三本书的开发流程，交叉提炼出最完整的新品开发标准流程。

## 阶段一：市场调研（1-2周）

**目标**：摸清赛道、竞品、用户。

**执行清单**：
1. 终端调研：收集竞品规格/价格/卖点/包装信息，制作竞品信息表
2. 消费者调研：用KANO模型区分基本需求/期望需求/兴奋需求
3. 用四大需求价值维度打分：受众面×使用频率×需求强度×符合度
4. 竞争格局分析：用爆品机会挖掘四象限（增长率×集中度）找机会窗口
5. 大数据调研（参考小米）：电商平台数据、供应链数据、用户行为数据

**输出物**：市场调研报告+竞品对比表+需求优先级排序

---

## 阶段二：产品定义（1周）

**目标**：确定做什么产品、什么属性、什么定位。

**执行清单**：
1. 绘制需求-产品属性QFD矩阵：需求×属性关联度打分，砍掉低关联属性
2. 确定产品四大属性定位：规格属性+物理特征+原料工艺功能+包装属性
3. 用核心突破法追问"为什么"和"只能这样吗"，拆到最底层重新定义产品
4. 确定产品在三级矩阵中的位置：流量品/利润品/种子品
5. 绑定核心消费场景，一句话说清"什么时候用"

**输出物**：产品立项报告（品类/市场/产品/渠道/价格/价值定位）

---

## 阶段三：成本与定价（3-5天）

**目标**：定出有竞争力的价格，倒推成本。

**执行清单**：
1. 目标成本法倒推：先定有竞争力的零售价→设企业和通路毛利率→倒推目标成本
2. 用弱势品牌8大法则选定竞争策略（新品牌推荐：规格加大价格持平 / 规格持平价格降低）
3. 临界点定价：99.9元而非100元，利用消费者心理账户
4. 设计价值阶梯：引流款（试用装）+利润款（正装）+锁客款（大包装/会员）
5. 用"一减二降三透明"降成本：减低频功能+降非核心标准+成本拆解透明化

**输出物**：定价方案+成本核算表+价值阶梯设计

---

## 阶段四：研发与测试（2-4周）

**目标**：做出1.0产品，小范围验证。

**执行清单**：
1. 明确市场部与研发部分工：市场部定属性/优先级/标杆竞品/成本目标，研发部负责技术实现
2. 产品属性比对测试（盲测）：本品vs竞品，雷达图可视化分析
3. 电商平台先跑数据（先卖后做）：2-4周测试包装/定价/卖点
4. 强制叫停机制：测试数据不达标必须叫停，不要硬上
5. 0.2秒包装测试：随机展示给目标用户，验证第一眼吸引力

**输出物**：1.0产品+盲测报告+电商测试数据

---

## 阶段五：定点试销（1-3个月）

**目标**：在特定区域/渠道验证，经历完整销售周期。

**执行清单**：
1. 选择1-2个核心区域做试销（聚焦利基市场建立根据地）
2. 根据试销数据优化产品：口味/规格/包装/价格/卖点
3. 收集用户真实反馈，重点看复购率和推荐率
4. 测试不同渠道组合的效果
5. 验证供应链的稳定性和交付能力

**输出物**：试销报告+优化后的2.0产品+渠道验证结果

---

## 阶段六：规模化上市

**目标**：试销验证通过后全面铺开。

**执行清单**：
1. 制定上市营销计划：冲突营销+触点效应+场景化传播
2. 卖点升级：从产品层卖点尝试升级到品牌层/理念层
3. 用蓝彻斯特引爆法则配置资源：聚焦核心品项→势能渠道→精准推广→饱和攻击
4. 同步启动私域漏斗：免费试吃→正装→大包装→会员→社群
5. 建立持续监测机制：用户满意度、复购率、竞品动态

**输出物**：上市方案+营销计划+持续监测仪表盘

---

## 全流程时间线

```
市场调研(1-2周) → 产品定义(1周) → 成本定价(3-5天) → 研发测试(2-4周) → 定点试销(1-3月) → 规模化上市
```

**总周期**：最短2个月，建议3-5个月。不要为了赶速度跳过试销阶段。
