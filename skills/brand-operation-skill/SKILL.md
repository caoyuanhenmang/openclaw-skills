# 草原很忙项目管理工作流

## 核心定位

本技能包是草原很忙项目管理全流程工作指南，基于麦肯锡商业经营管理方法论体系，为AI Agent提供完整的项目分析、项目管理、决策支持、战略规划和问题诊断能力。

## 五大应用场景

### 场景一：新项目/新赛道评估（项目分析）

**适用时机**：
- 评估是否要进入一个新赛道（如葵花籽仁油、亚麻籽油）
- 评估是否要上马一个新产品线
- 评估是否要开拓一个新渠道

**方法论组合拳**：
```
第一步：企业三层面增长框架判断
    → 这个项目在企业战略中的定位？
    → 是核心业务、成长业务还是未来机会？
    
第二步：STP战略定位
    → 市场细分 → 目标市场选择 → 市场定位
    → 卖给谁？为什么选我？
    
第三步：价值主张画布验证
    → 客户任务/痛点/增益 ↔ 产品/服务/解决方案
    → 产品是否精准匹配需求？
    
第四步：商业模式画布闭环
    → 9模块全局商业闭环
    → 商业模式是否完整？能否盈利？
    
第五步：五阶数据分析支撑
    → 采集市场数据 → 清洗分析 → 价值解读 → 决策应用
    → 数据是否支撑决策？
```

**输出成果**：项目评估报告（飞书文档）

**执行步骤**：
1. 读取 [references/new-project-assessment-workflow.md](references/new-project-assessment-workflow.md)
2. 按流程逐步执行
3. 输出项目评估报告

---

### 场景二：项目管理与运营（项目执行）

**适用时机**：
- 项目立项后的执行管理
- 日常运营管理
- 渠道运营管理

**方法论组合拳**：
```
第一步：麦肯锡7S模型诊断
    → 评估组织能力是否支撑项目落地
    → 价值观、战略、结构、制度、员工、技能、风格
    
第二步：AIDAL漏斗全链路转化
    → 认知 → 兴趣 → 欲望 → 行动 → 忠诚
    → 每个环节的转化策略是什么？
    
第三步：五阶数据分析监控
    → 数据采集 → 清洗分析 → 解读应用
    → 用数据驱动持续优化
    
第四步：商业模式画布动态调整
    → 根据市场反馈调整商业模式
    → 优化渠道、客户关系、成本结构
```

**输出成果**：项目运营方案、渠道运营方案、月度/季度运营报告

**执行步骤**：
1. 读取 [references/project-operation-workflow.md](references/project-operation-workflow.md)
2. 按流程逐步执行
3. 输出运营方案或报告

---

### 场景三：日常经营决策（战术层面）

**适用时机**：
- 产品定价决策
- 渠道选择决策
- 营销活动策划
- 客户运营策略

**方法论组合拳**：
```
小决策（单一环节）
    → 使用单一工具快速决策
    → 如：客户定位 → STP战略
    
中决策（多环节联动）
    → 使用2-3个工具组合
    → 如：产品优化 → 价值主张画布 + AIDAL漏斗
    
大决策（全局影响）
    → 使用完整方法论体系
    → 如：品牌战略 → 完整方法论流程
```

**决策类型与工具匹配**：

| 决策类型 | 推荐工具组合 | 执行指南 |
|---------|------------|---------|
| 产品定价 | 五阶数据分析 + STP战略 | [references/pricing-decision.md](references/pricing-decision.md) |
| 渠道选择 | STP战略 + 商业模式画布 | [references/channel-decision.md](references/channel-decision.md) |
| 营销活动 | AIDAL漏斗 + 五阶数据分析 | [references/marketing-campaign.md](references/marketing-campaign.md) |
| 客户运营 | 价值主张画布 + AIDAL漏斗 | [references/customer-operation.md](references/customer-operation.md) |

### 场景四：企业战略规划（战略层面）

**适用时机**：
- 年度战略规划
- 三年发展规划
- 业务转型决策
- 组织架构调整

**方法论组合拳**：
```
第一步：企业三层面增长框架
    → 核心业务（草原很忙现有品牌）
    → 成长业务（新品牌、新渠道）
    → 未来机会（新赛道探索）
    
第二步：麦肯锡7S模型
    → 评估组织能力是否支撑战略
    → 需要调整哪些要素？
    
第三步：商业模式画布
    → 梳理每个业务板块的商业模式
    → 优化资源配置
    
第四步：STP战略
    → 每个业务板块的市场定位
    → 避免业务冲突
```

**输出成果**：年度战略规划报告、组织架构调整方案、资源配置方案

**执行步骤**：
1. 读取 [references/strategic-planning-workflow.md](references/strategic-planning-workflow.md)
2. 按流程逐步执行
3. 输出战略规划报告

---

### 场景五：问题诊断与优化（诊断层面）

**适用时机**：
- 业务增长乏力
- 团队执行力差
- 客户流失率高
- 利润率下滑

**方法论组合拳**：
```
第一步：五阶数据分析
    → 数据诊断问题出在哪个环节
    → 对比法 + 分类法 + 排序法
    
第二步：麦肯锡7S模型
    → 组织能力诊断
    → 是价值观、战略、结构、制度、员工、技能还是风格的问题？
    
第三步：价值主张画布
    → 产品是否还匹配客户需求？
    → 客户需求是否发生变化？
    
第四步：AIDAL漏斗
    → 问题出在哪个环节？
    → 认知层、兴趣层、欲望层、行动层还是忠诚层？
```

**输出成果**：问题诊断报告、优化方案

**执行步骤**：
1. 读取 [references/problem-diagnosis-workflow.md](references/problem-diagnosis-workflow.md)
2. 按流程逐步执行
3. 输出诊断报告和优化方案

## 快速判断流程

**当用户提出需求时，按以下流程判断使用哪个场景**：

```
用户提出需求
    ↓
需求类型判断
    ├─ 评估新项目/新赛道/新产品？ → 场景一：新项目评估
    ├─ 管理已立项项目或日常运营？ → 场景二：项目管理
    ├─ 做具体战术决策（定价/渠道/营销/客户）？ → 场景三：日常决策
    ├─ 制定年度/三年战略规划？ → 场景四：战略规划
    └─ 业务出现问题需要诊断？ → 场景五：问题诊断
    ↓
读取对应的执行指南
    ↓
按流程执行并输出成果
```

## 核心原则

### 1. 系统化思维

- 不是每次都要用所有工具，而是根据场景选择合适的工具组合
- 小问题用小工具，大问题用大工具组合
- 核心是形成"数据驱动决策"的思维习惯

### 2. 方法论优先级

在草原很忙的实际工作中，方法论使用优先级：

1. **云盘知识库** → 优先使用已有方法论（如商业基因战略、GROW模型）
2. **本技能包** → 使用麦肯锡方法论体系
3. **自主判断** → 结合实际情况灵活运用

### 3. 输出标准

所有输出成果必须符合草原很忙VI视觉识别系统规范：
- 主绿色：#1fb25a（标志主体、封面主色）
- 深绿色：#0c7b46（标题文字、边框）
- 金色：#DAA520（促销标签、点缀）
- 字体规范：标题用黑体加粗，正文用思源黑体

## 注意事项

1. **草原很忙业务模式**：S2B2C业务模式，赋能上游工厂、下游销售渠道
2. **翻牌时机**：线下云连锁门店达到500+、自有品牌产品达到50+
3. **核心渠道**：品牌旗舰店、达人带货、云连锁门店、私域运营、分销店群
4. **数据驱动**：所有决策必须有数据支撑，至少3个数据源
