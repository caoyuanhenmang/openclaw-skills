# 项目运营管理工作流

## 适用场景

项目立项后的执行管理、日常运营管理、渠道运营管理。

---

## 工作流程

### 月度运营规划（每月初）

**核心问题**：本月运营重点是什么？

**执行步骤**：

#### 步骤1：AIDAL漏斗现状分析

**认知层现状**：
- 本月曝光量、触达人数
- 品牌认知度、搜索指数
- 渠道覆盖情况

**兴趣层现状**：
- 点击率、咨询量
- 加购率、收藏率
- 用户停留时长

**欲望层现状**：
- 转化率、下单率
- 客单价、GMV
- 用户行为路径

**行动层现状**：
- 成交量、成交额
- 复购率、退货率
- 支付成功率

**忠诚层现状**：
- 复购客户数、复购金额
- 用户满意度、NPS
- 转介绍率

#### 步骤2：识别薄弱环节

**漏斗转化率分析**：
```
认知 → 兴趣：点击率（行业标准3-5%）
兴趣 → 欲望：加购率（行业标准2-3%）
欲望 → 行动：转化率（行业标准1-2%）
行动 → 忠诚：复购率（行业标准20-30%）
```

**薄弱环节判断**：
- 转化率低于行业标准50% → 重点优化
- 转化率低于行业标准20% → 持续观察
- 转化率高于行业标准 → 保持优势

#### 步骤3：制定运营策略

**认知层策略**：
- 价值前置输出（内容营销）
- 弱品牌露出（软性植入）
- 渠道拓展（新流量入口）

**兴趣层策略**：
- 差异化定位（人无我有）
- 场景化包装（解决具体问题）
- 社交证明（用户证言、KOL背书）

**欲望层策略**：
- 真实场景展示（使用前后对比）
- 情绪绑定（美好生活的联想）
- 紧迫感营造（限时优惠）

**行动层策略**：
- 流程极简（一键下单）
- 即时刺激（优惠券、赠品）
- 零风险承诺（退换货保障）

**忠诚层策略**：
- 首访关怀（新客户专属服务）
- 标签化管理（个性化推荐）
- 专属权益（会员等级、积分）
- 转介绍激励（老带新奖励）

#### 步骤4：资源配置

**人力分配**：
- 内容团队：认知层、兴趣层
- 销售团队：欲望层、行动层
- 客服团队：忠诚层

**预算分配**：
- 广告投放：认知层（40%）、兴趣层（30%）
- 促销活动：欲望层（20%）、行动层（10%）
- 客户维护：忠诚层（根据实际情况）

**输出**：《月度运营计划》

---

### 周度执行监控（每周）

**核心问题**：本周数据表现如何？

**执行步骤**：

#### 步骤1：数据采集

**关键指标**：
```
流量指标：曝光量、点击量、访问量
转化指标：点击率、转化率、成交率
营收指标：GMV、客单价、毛利率
用户指标：新增用户、活跃用户、复购用户
```

#### 步骤2：数据清洗

**异常数据处理**：
- 识别异常数据（与上周对比变化>50%）
- 核实异常原因（系统问题、活动影响、外部因素）
- 剔除或标注异常数据

#### 步骤3：数据分析

**对比法**：
- 环比上周：增长/下降
- 同比上月：增长/下降
- 对标目标：完成率

**分类法**：
- 按渠道分类：哪个渠道表现最好？
- 按产品分类：哪个产品销量最高？
- 按用户分类：哪类用户价值最高？

**排序法**：
- 按贡献度排序：哪个因素贡献最大？
- 按问题严重性排序：哪个问题最紧迫？

#### 步骤4：问题诊断

**5Why溯源法**：
```
问题：本周转化率下降10%
→ Why 1：为什么下降？因为流量质量下降
→ Why 2：为什么流量质量下降？因为投放渠道变化
→ Why 3：为什么投放渠道变化？因为预算调整
→ Why 4：为什么预算调整？因为测试新渠道
→ Why 5：为什么测试新渠道？因为老渠道成本上升
→ 根因：需要优化新渠道投放策略
```

#### 步骤5：调整优化

**微调策略**：
- 调整投放预算分配
- 优化内容方向
- 调整促销力度

**输出**：《周度数据报告》

### 季度能力诊断（每季度）

**核心问题**：组织能力是否支撑业务增长？

**执行步骤**：

#### 步骤1：麦肯锡7S模型诊断

**硬件要素诊断**：

1. **战略诊断**
   - 战略目标是否清晰？
   - 战略与价值观是否匹配？
   - 战略是否可拆解为具体目标？

2. **结构诊断**
   - 组织架构是否合理？
   - 汇报关系是否清晰？
   - 权责是否对等？

3. **制度诊断**
   - 制度是否导向一致？
   - 制度是否简洁易执行？
   - 制度是否动态迭代？

**软件要素诊断**：

4. **共同价值观诊断**
   - 团队是否认同价值观？
   - 价值观是否作为决策依据？
   - 是否处罚违反价值观的行为？

5. **员工诊断**
   - 招聘是否匹配需求？
   - 员工结构是否匹配业务阶段？
   - 价值观匹配度是否>70%？

6. **技能诊断**
   - 员工能力是否匹配岗位？
   - 技能是否随战略迭代？
   - 是否有培训体系？

7. **风格诊断**
   - 管理风格是否匹配价值观？
   - 决策风格是否适配业务节奏？
   - 管理者是否以身作则？

#### 步骤2：识别能力短板

**短板判断标准**：
- 评分<3分（满分5分）→ 严重短板
- 评分3-4分 → 需要提升
- 评分≥4分 → 保持优势

#### 步骤3：制定提升计划

**分层联动逻辑**：
```
第一优先级：共同价值观（根基层）
    → 问题：价值观不清晰
    → 行动：重新定义价值观、全员培训

第二优先级：战略（方向层）
    → 问题：战略不清晰
    → 行动：制定年度战略、拆解目标

第三优先级：结构、制度（支撑层）
    → 问题：权责不清
    → 行动：调整组织架构、明确职责

第四优先级：员工、技能（执行层）
    → 问题：能力不足
    → 行动：招聘、培训、淘汰

贯穿始终：风格（氛围层）
    → 问题：管理风格不当
    → 行动：管理者培训、以身作则
```

**输出**：《组织能力评估报告》

---

### 年度战略调整（每年）

**核心问题**：明年增长引擎是什么？

**执行步骤**：

#### 步骤1：企业三层面增长框架评估

**第一层面（核心业务）评估**：
- 现金流贡献是否稳定？（≥60%）
- 毛利率是否高于行业平均？（+5%）
- 市占率是否进入前20%？
- 增长是否放缓？（<10%）

**第二层面（成长业务）评估**：
- 成长业务是否跑通盈利模型？（ROI≥1:1.5）
- 成长业务营收占比是否提升？（>20%）
- 成长业务是否形成护城河？

**第三层面（未来机会）评估**：
- 是否有种子业务在培育？
- 种子业务是否有认知沉淀？
- 是否有种子业务跑通升级？

#### 步骤2：调整资源分配

**基准比例**：7:2:1

**动态调整**：
```
核心业务增长放缓 → 提高成长业务占比（6:2.5:1.5）
核心业务未达标 → 提高核心业务占比（9:0.5:0.5）
行业迭代快 → 提高未来业务占比（6:2:2）
```

#### 步骤3：STP战略调整

**每个业务板块**：
- 市场定位是否需要调整？
- 目标客户是否发生变化？
- 差异化优势是否还成立？

**输出**：《年度战略规划》

---

## 输出成果

1. **月度运营计划**（每月初）
2. **周度数据报告**（每周）
3. **组织能力评估报告**（每季度）
4. **年度战略规划**（每年）

---

## 注意事项

1. **数据驱动**：所有决策必须有数据支撑
2. **迭代优化**：持续优化，避免一次性大调整
3. **团队协同**：各部门协同配合，避免信息孤岛
4. **客户导向**：始终以客户需求为中心
