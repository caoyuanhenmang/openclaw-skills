# 新项目评估工作流

## 适用场景

评估是否要进入一个新赛道、上马一个新产品线、开拓一个新渠道。

---

## 完整工作流程

### 阶段一：企业三层面定位（筛选阶段）

**耗时**：1-2天

**核心问题**：这个项目在企业战略中的定位？

**执行步骤**：

1. **判断项目关联度**
   - 核心资源（技术、人力、渠道、品牌）复用率评估
   - 与主业关联度打分（满分10分：资源复用4分 + 用户重合3分 + 供应链重合3分）
   - 判断标准：关联度≥4分、核心资源复用率≥60%

2. **确定项目层级**
   ```
   第一层面：核心业务
       → 判断标准：现金流贡献≥60%、毛利率高于行业平均5%、市占率前20%
       → 资源分配：70%
       
   第二层面：成长业务
       → 判断标准：关联度≥4分、核心资源复用率≥60%、小范围测试ROI≥1:1.5
       → 资源分配：20%
       
   第三层面：未来机会
       → 判断标准：低成本试错（双10%红线）、趋势跟踪、认知积累
       → 资源分配：10%
   ```

3. **输出结论**
   - 项目定位：核心业务 / 成长业务 / 未来机会
   - 资源分配比例
   - 是否进入下一阶段（核心或成长业务进入，未来机会单独处理）

**决策点**：
- ✅ 关联度≥4分 → 进入阶段二
- ❌ 关联度<4分 → 直接否决或降级为未来机会

---

### 阶段二：STP战略定位

**耗时**：2-3天

**核心问题**：卖给谁？为什么选我？

**执行步骤**：

#### 步骤1：市场细分（三维拆分法）

**维度一：地域维度**
- 全国市场 / 区域市场 / 本地市场
- 一线城市 / 新一线城市 / 二三线城市 / 下沉市场
- 线上市场 / 线下市场

**维度二：人口统计维度**
- 年龄段：Z世代、新中产、银发族等
- 收入水平：高端、中端、大众
- 家庭结构：单身、新婚、有孩、三代同堂
- 消费习惯：品质型、性价比型、尝鲜型

**维度三：需求动机维度**
- 核心需求：健康、美味、便捷、社交、身份认同
- 痛点强度：致命痛点（必须解决）、重度痛点（强烈希望解决）、轻度痛点（有更好没有也行）
- 使用场景：早餐、午餐、晚餐、零食、送礼

**输出**：《细分市场清单》

#### 步骤2：目标市场选择（三维评估法）

**维度一：规模适配性**
- 市场规模是否足够大？（绝对值 + 增长率）
- 与企业当前体量是否匹配？
- 评估标准：
  ```
  市场规模评分（满分30分）
  ├─ 市场绝对规模（10分）：>10亿得10分，5-10亿得7分，1-5亿得4分，<1亿得1分
  ├─ 年增长率（10分）：>15%得10分，10-15%得7分，5-10%得4分，<5%得1分
  └─ 细分赛道空间（10分）：龙头市占率<30%得10分，30-50%得7分，>50%得4分
  ```

**维度二：触达可行性**
- 能否有效触达目标用户？
- 触达成本是否可控？
- 评估标准：
  ```
  触达可行性评分（满分30分）
  ├─ 渠道成熟度（10分）：现有渠道可直接触达得10分，需要新建渠道得5分
  ├─ 获客成本（10分）：CAC<LTV的1/3得10分，1/3-1/2得7分，>1/2得4分
  └─ 触达效率（10分）：转化率>5%得10分，2-5%得7分，<2%得4分
  ```

**维度三：竞争优势**
- 是否有差异化优势？
- 竞争强度如何？
- 评估标准：
  ```
  竞争优势评分（满分40分）
  ├─ 差异化程度（15分）：强差异化得15分，中等差异化得10分，弱差异化得5分
  ├─ 竞争强度（15分）：竞争分散（CR5<30%）得15分，中等竞争得10分，竞争激烈得5分
  └─ 护城河（10分）：有专利/渠道/品牌护城河得10分，部分护城河得7分，无护城河得3分
  ```

**综合评分**：
- 总分≥80分：A级赛道（优先进入）
- 总分60-79分：B级赛道（可以进入，需差异化）
- 总分40-59分：C级赛道（谨慎进入，需强差异化）
- 总分<40分：D级赛道（不建议进入）

**输出**：《核心目标市场确认书》

#### 步骤3：市场定位

**定位标准句式**：
```
在【细分市场】中，为【目标用户】提供【核心价值】，区别于【竞争对手】的【差异化优势】。
```

**定位落地执行表**：

| 触点 | 定位传递方式 | 具体动作 |
|------|------------|---------|
| **产品包装** | 视觉符号 + 一句话卖点 | 设计风格、主色调、核心卖点文案 |
| **广告传播** | 核心信息重复 | 广告语、视频脚本、投放素材 |
| **销售话术** | 说服逻辑 | 销售培训、话术手册 |
| **渠道展示** | 场景化体验 | 终端陈列、体验区设计 |
| **用户口碑** | 价值验证 | 用户证言、第三方背书 |

**输出**：《定位落地执行表》

**决策点**：
- ✅ 综合评分≥60分 → 进入阶段三
- ❌ 综合评分<60分 → 直接否决或重新定位

---

### 阶段三：价值主张验证

**耗时**：1-2天

**核心问题**：产品是否精准匹配需求？

**执行步骤**：

#### 步骤1：客户画像构建

**客户任务**：
- 本质目标是什么？（不是产品，而是客户想解决的问题）
- 任务场景：工作场景、生活场景、社交场景
- 任务频率：高频、中频、低频
- 任务重要性：核心任务、辅助任务

**客户痛点**（分级）：
- **致命痛点**：不解决就会放弃购买（如食品安全问题）
- **重度痛点**：强烈希望解决，愿意付费（如价格太贵、购买不便）
- **轻度痛点**：有更好，没有也行（如包装不够精美）

**客户增益**（分层）：
- **必要增益**：基础期望（如产品质量达标）
- **期望增益**：明确希望获得的（如性价比高）
- **惊喜增益**：超出预期的（如赠品、售后服务）

#### 步骤2：价值主张设计

**产品/服务** → 匹配客户任务
- 产品功能是否直接解决客户任务？
- 产品形态是否符合客户使用习惯？
- 产品定价是否符合客户支付能力？

**痛点解决方案** → 匹配客户痛点
- 致命痛点是否完全解决？
- 重度痛点是否有效缓解？
- 轻度痛点是否有优化？

**增益供给方案** → 匹配客户增益
- 必要增益是否达标？
- 期望增益是否满足？
- 惊喜增益是否有设计？

**输出**：《价值主张匹配表》

| 客户需求 | 需求类型 | 产品/服务 | 匹配度 | 备注 |
|---------|---------|----------|-------|------|
| 客户任务1 | 核心任务 | 产品功能1 | ★★★★★ | 完全匹配 |
| 客户痛点1 | 致命痛点 | 解决方案1 | ★★★★★ | 完全解决 |
| 客户增益1 | 惊喜增益 | 增益方案1 | ★★★★☆ | 超出预期 |

**决策点**：
- ✅ 核心需求匹配度≥4星 → 进入阶段四
- ❌ 核心需求匹配度<4星 → 调整产品或重新定位

---

### 阶段四：商业闭环设计

**耗时**：2-3天

**核心问题**：商业模式是否完整？能否盈利？

**执行步骤**：

#### 商业模式画布（9模块）

**第一层：客户价值层（商业起点）**

1. **客户细分**
   - 核心客群是谁？（来自阶段二的STP定位）
   - 客户画像是否清晰？
   - 付费意愿如何？

2. **价值主张**
   - 核心价值是什么？（来自阶段三的价值主张）
   - 是否可量化？
   - 是否有落地支撑？

**第二层：价值交付层（落地过程）**

3. **渠道通路**
   - 如何触达客户？（线上/线下/公域/私域）
   - 渠道是否匹配客群习惯？
   - 渠道ROI如何？

4. **客户关系**
   - 如何留住客户？（会员体系、私域运营、售后服务）
   - 如何提升复购？
   - 如何降低选择成本？

5. **关键业务**
   - 核心要做什么事？（生产、研发、营销、服务）
   - 是否聚焦核心竞争力？
   - 是否做了减法？

**第三层：盈利支撑层（可持续保障）**

6. **收入来源**
   - 钱从哪些口子进？（产品销售、增值服务、会员费、广告）
   - 核心收入是什么？
   - 是否有衍生收入？

7. **核心资源**
   - 手上有什么压箱底宝贝？（技术、品牌、渠道、供应链）
   - 是否不可复制？
   - 是否不可替代？

8. **重要伙伴**
   - 谁能帮你一起干？（供应商、渠道商、服务商）
   - 价值互换是什么？
   - 资源是否互补？

9. **成本结构**
   - 钱花在哪些地方？（生产成本、营销成本、人力成本、运营成本）
   - 成本结构是否合理？
   - 是否有规模效应？

**输出**：《商业模式画布》

**商业闭环检验标准**：
```
✅ 客户细分 + 价值主张：是否精准匹配？
✅ 渠道通路 + 客户细分：是否有效触达？
✅ 收入来源 > 成本结构：是否盈利？
✅ 核心资源 + 关键业务：是否支撑价值主张？
✅ 重要伙伴：是否补足短板？
```

**决策点**：
- ✅ 商业闭环完整 → 进入阶段五
- ❌ 商业闭环不完整 → 调整商业模式或补充资源

---

### 阶段五：数据支撑决策

**耗时**：2-3天

**核心问题**：数据是否支撑决策？

**执行步骤**：

#### 步骤1：精准数据采集

**决策三问法**：
1. 这个数据用来做什么决策？
2. 这个决策会影响哪些业务？
3. 这个数据的准确度要求是多少？

**三大维度数据采集**：

**门店维度**（如果是线下业务）：
- 门店数量、分布、规模
- 单店营收、客流、转化率
- 区域市场竞争格局

**产品维度**：
- 市场规模、增长率、竞争格局
- 产品差异化程度、价格区间
- 供应链稳定性、成本结构

**客户维度**：
- 目标客群规模、消费能力、消费习惯
- 客户痛点、需求偏好、购买决策路径
- 客户生命周期价值（LTV）

**数据来源**：
- 行业研究报告（艾瑞、易观、第一财经商业数据中心）
- 政府统计数据（国家统计局、行业协会）
- 竞品公开数据（财报、官网、新闻报道）
- 第三方数据平台（天眼查、企查查、百度指数）
- 实地调研数据（问卷调研、访谈、观察）

#### 步骤2：数据清洗校准

**统一口径**：
- 时间范围：统一为年度/季度/月度
- 地域范围：全国/区域/城市
- 统计标准：零售额/销售额/出货额

**填补缺失**：
- 行业平均值填补
- 相似市场推算
- 专家访谈估算

**异常值处理**：
- 识别异常数据（3σ原则）
- 核实异常原因
- 剔除或修正

#### 步骤3：轻量化分析

**对比法**：
- 时间对比：同比、环比
- 空间对比：不同区域、不同渠道
- 对标对比：与竞品、与行业平均

**分类法**：
- 按属性分类：高端/中端/大众
- 按行为分类：高频/中频/低频
- 按价值分类：高价值/中价值/低价值

**排序法**：
- 按重要性排序：核心指标、辅助指标
- 按优先级排序：立即行动、持续观察、暂不处理
- 按影响力排序：关键因素、次要因素

#### 步骤4：场景化解读

**5Why溯源法**：
```
问题：市场增长率下滑
→ Why 1：为什么下滑？因为竞品价格更低
→ Why 2：为什么竞品价格更低？因为供应链成本更低
→ Why 3：为什么供应链成本更低？因为规模化采购
→ Why 4：为什么没有规模化采购？因为采购量不够大
→ Why 5：为什么采购量不够大？因为市场开拓不足
→ 根因：市场开拓不足，需要扩大市场份额
```

**场景关联**：
- 数据背后的业务场景是什么？
- 数据变化与哪些因素相关？
- 数据趋势是否符合行业规律？

#### 步骤5：决策应用

**小切口切入**：
- 先在一个小范围验证（一个城市、一个渠道、一个产品）
- 验证成功再放大
- 避免一次性大投入

**指令轻量化**：
- 决策指令要具体可执行
- 明确责任人、时间节点、验收标准
- 避免模糊指令

**迭代式验证**：
- 每周复盘数据
- 每月调整策略
- 每季度评估效果

**输出**：《项目评估报告》

**报告结构**：
```
一、项目概述
    1. 项目背景
    2. 评估目的
    3. 评估范围

二、市场定位分析（STP）
    1. 市场细分
    2. 目标市场选择（三维评估得分）
    3. 市场定位

三、价值主张验证
    1. 客户画像
    2. 价值主张匹配表

四、商业闭环设计
    1. 商业模式画布
    2. 盈利模式分析

五、数据支撑分析
    1. 市场规模数据
    2. 竞争格局数据
    3. 财务预测数据

六、风险评估与应对
    1. 市场风险
    2. 竞争风险
    3. 运营风险

七、结论与建议
    1. 综合评级（A/B/C/D）
    2. 进入/放弃建议
    3. 关键成功因素
    4. 行动计划
```

## 决策树总结

```
新项目评估
    ↓
【阶段一】企业三层面定位
    ├─ 关联度≥4分 → 进入阶段二
    └─ 关联度<4分 → 否决或降级
    ↓
【阶段二】STP战略定位
    ├─ 综合评分≥60分 → 进入阶段三
    └─ 综合评分<60分 → 否决或重新定位
    ↓
【阶段三】价值主张验证
    ├─ 核心需求匹配度≥4星 → 进入阶段四
    └─ 核心需求匹配度<4星 → 调整产品
    ↓
【阶段四】商业闭环设计
    ├─ 商业闭环完整 → 进入阶段五
    └─ 商业闭环不完整 → 调整模式
    ↓
【阶段五】数据支撑决策
    ├─ 数据支撑 → 输出报告，建议进入
    └─ 数据不支撑 → 否决或调整
```

## 时间与人力投入

**总耗时**：8-13天（可并行压缩至5-7天）

**人力配置**：
- 项目负责人：1人（全程参与）
- 数据分析师：1人（阶段五）
- 行业研究员：1人（阶段二、五）

## 注意事项

1. **草原很忙业务模式**：S2B2C，赋能上游工厂、下游销售渠道
2. **核心渠道匹配度评估**：
   - 品牌旗舰店：★★★★★
   - 达人带货：★★★★★
   - 私域运营：★★★★★
   - 云连锁门店：★★★★☆
   - 分销店群：★★★☆☆
3. **翻牌时机判断**：线下云连锁门店500+、自有品牌产品50+
