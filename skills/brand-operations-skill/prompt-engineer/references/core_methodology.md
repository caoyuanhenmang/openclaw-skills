# 核心方法论框架

## 一、框架选择原则

```
简单场景（单一任务、单一环节）→ CREATE框架
复杂场景（多环节、多部门协同、全链路流转）→ 双轨8模块框架
视觉生成场景 → 四大模块 + 视觉DNA + 品牌VI参数字典
```

---

## 二、CREATE框架（极简通用版）

**适用场景**：单一任务、单一环节、非专业业务人员使用

| 缩写 | 模块名称 | 核心作用 | 撰写要点 |
|-----|---------|---------|---------|
| **C** | Context业务背景 | 构建信息茧房，框定思考边界 | 明确：行业赛道、商业模式、使用场景、核心业务目标 |
| **R** | Role专家角色 | 赋予AI精准专业身份 | 明确：行业年限+赛道经验+核心能力+服务对象 |
| **E** | Examples标杆示例 | 明确"好的标准"，降低沟通成本 | 提供1-3个标杆案例，要求AI模仿核心逻辑、结构、调性 |
| **A** | Action具体任务 | 拆解可落地的执行步骤 | 明确：先做什么、再做什么、最终交付什么 |
| **T** | Tone/Tags调性标签 | 锁定品牌统一调性 | 文本类：锁定品牌统一话术；视觉类：锁定品牌VI参数 |
| **E** | Execution交付格式 | 指定输出标准，实现输出即可用 | 明确：格式类型、结构、篇幅、适配工具 |

**记忆口诀**：**C**ontext背景 **R**ole角色 **E**xamples示例 **A**ction任务 **T**one调性 **E**xecution格式

---

## 三、双轨8模块框架（企业级管控版）

**适用场景**：复杂业务场景、多环节协同、专业提示词工程师使用

| 模块序号 | 模块名称 | 核心管控价值 | 核心要求 |
|---------|---------|-------------|---------|
| **1** | 角色定位与业务背景 | 锁定AI专业身份，锚定战略目标 | 明确企业增长视角下的业务背景、产业链环节、战略目标 |
| **2** | 业务边界与红线规则 | 划定禁止项，从源头规避风险 | 明确"绝对不能做什么"：合规红线、价格管控、品牌禁忌、涉密要求 |
| **3** | 输入基准与脱敏规则 | 锁死唯一数据源，对抗幻觉与泄密 | 明确AI仅能使用指定数据源，无依据不输出，信息不足标注数据缺失 |
| **4** | 执行逻辑与分析模型 | 固定执行步骤与商业模型 | 明确分步执行流程，固定商业分析模型（SWOT/4P/波特五力/RFM） |
| **5** | 品牌规范与调性 | 锁定品牌统一标准 | 严格遵循品牌VI规范、统一话术标准，保障全渠道一致性 |
| **6** | 交付格式与工具适配 | 明确输出标准，实现输出即可用 | 明确输出格式、结构、篇幅，适配企业内部协同工具 |
| **7** | 校验与验收标准 | 设定AI自我核查规则 | 明确验收的核心维度，要求AI输出前对照标准逐一核查 |
| **8** | 多轮迭代规则 | 锁定修改边界，避免整体跑偏 | 明确仅针对指定修改项调整，其余内容保持不变 |

**记忆口诀**：角色背景→边界红线→输入脱敏→执行模型→品牌调性→交付格式→校验验收→迭代规则

## 四、视觉生成四大模块

**适用场景**：所有视觉生成场景（电商主图、详情页、直通车、分销手册等）

### 模块1：视觉重心（Visual Focus）

**作用**：确定画面的核心焦点和第一视觉冲击点

**包含要素**：
- 画面核心主体（产品本身）
- 镜头视角（俯视/平视/仰视）
- 布光参数（光源类型、光照角度、色温）
- 产品质感表现（glossy油亮/juicy多汁/crunchy酥脆等）
- 视觉DNA规范嵌入（9大风格之一）

**撰写模板**：
```
【视觉DNA完整嵌入此处】，杰作，最佳画质，8K超清分辨率，
商业级电商摄影，超写实，高细节，锐化清晰，专业色彩校准，无噪点；
画面第一视觉重心为【产品名称】主体，
产品占画面核心视觉区域，为画面绝对焦点，
全程无透视变形，产品质感表现严格遵循视觉DNA规范。
```

---

### 模块2：色彩心理（Color Psychology）

**作用**：通过色彩传递心理暗示，强化产品调性

**包含要素**：
- 主色调（必须100%匹配产品图）
- 辅助色（符合视觉DNA规范）
- 点缀色（提升视觉层次）
- 色彩心理暗示（安全感/食欲感/高级感等）

**撰写模板**：
```
画面主色调100%匹配【标准产品图】提取的产品主色调，
辅助色与点缀色贴合视觉DNA的色彩规范与产品品类属性，
整体色彩视觉冲击力强，无任何与产品主色调冲突的违和色系。
```

---

### 模块3：排版结构（Layout Structure）

**作用**：确定画面构图、文案布局和信息层级

**包含要素**：
- 构图方式（黄金分割/对称/网格等）
- 文案位置（标题/副标题/卖点/行动呼吁）
- 字体风格（匹配视觉DNA）
- 信息层级（主次分明）

**撰写模板**：
```
- 左上角：主标题使用【产品名称】，采用【字体风格】，
  副标题引用【核心卖点】；次卖点搭配对应极简图标横向排列。
- 底部：设置与产品主色调呼应的高饱和度深色底条，
  承载行动呼吁引导文案，文案围绕核心购买人群撰写专属购买理由。
- 所有文案、元素不遮挡产品主体，信息层级清晰。
```

---

### 模块4：元素提取（Element Extraction）

**作用**：确定辅助元素的类型、呈现形式和位置

**包含要素**：
- 背景元素（产地/品类/文化相关）
- 装饰元素（道具/纹样/符号）
- 功能性元素（图标/分割线/引导线）
- 氛围烘托元素（光影/粒子/纹理）

**撰写模板**：
```
- 包装背书：背景中斜向放置产品包装，建立实物联想，
  强化产品品类与产地属性，严格参考【标准产品图】中的包装样式。
- 画面四周零星散落与产品品类、核心产地、原材料强相关的原生辅助元素，
  搭配自然光影动效，增加画面层级感，
  整体构图平衡，商业质感强，产品品类特色鲜明。
```

## 五、品牌VI参数字典

### 5.1 核心色彩体系（6:3:1黄金法则）

**适用说明**：此框架适用于所有品牌，品牌色不固定，根据具体品牌VI规范填充。

| 色彩类型 | 占比 | 心理暗示 | 适用场景 |
|---------|------|---------|---------|
| **主色调** | 60% | 品牌核心调性、安全感、纯净感 | 背景大面积留白、卡片底色、主视觉区域 |
| **辅助色** | 30%（合计） | 品牌个性、现代感、活力感 | 模块分割线、核心字体、视觉符号点缀 |
| **点缀色** | 10% | 匠心、尊贵、亮点 | 价格标签、买点Icon、高溢价产品局部光泽 |

**变量说明**：
```
{{主色调}}：根据品牌VI规范提取，占比60%
{{辅助色1}}：根据品牌VI规范提取，占比15%
{{辅助色2}}：根据品牌VI规范提取，占比15%
{{点缀色}}：根据品牌VI规范提取，占比10%
```

### 5.2 使用规则

```
1. 所有视觉生成必须严格遵循6:3:1色彩法则（主色60% + 辅助色30% + 点缀色10%）
2. 品牌色必须100%匹配品牌方提供的VI规范
3. 禁止使用与品牌调性不符的色彩
4. 如品牌方未提供VI规范，需根据产品属性、目标人群、品类特征智能适配色彩体系
```

## 六、强制执行规则体系

### 6.1 品牌LOGO强制管控规则

```
1. 所有电商主图（含第1张主图）全程禁止单独放置、出现任何品牌LOGO
2. 仅详情页首屏KV海报，强制在画面左上角出现1次品牌LOGO
3. 详情页其余所有板块、主图全系列、直通车图、供应商产品手册、达人选品手册，全程禁止出现任何形式的品牌LOGO
4. 供应商产品手册、达人选品手册，全程禁止出现任何品牌LOGO、品牌标识相关元素
```

---

### 6.2 文案内容合规强制规则

```
1. 所有涉及产品名称的位置，必须统一调用{{产品名称}}变量
2. 主图文案可出现「线下同款」表述，但绝对禁止提及具体门店数量、门店规模相关数据
3. 所有文案内容必须100%来自提供的核心报告，绝对禁止出现任何虚构的优惠促销活动、福利政策、价格折扣相关内容
4. 第1张主图的行动呼吁引导文案，必须围绕核心购买人群撰写专属购买理由，全程禁止出现任何活动、促销、折扣相关内容
5. 所有文案禁止胡编乱造、无中生有，所有卖点、参数、信息必须有核心报告作为依据，严格遵守广告法与电商平台合规要求
```

---

### 6.3 画面布局强制规则

```
1. 供应商产品手册图、达人选品手册图，必须强制固定左右分屏比例：
   左侧画面宽度占比75%，右侧画面宽度占比25%
2. 所有生成画面必须严格遵循对应风格的视觉DNA规范
3. 主色调100%匹配品牌VI参数字典（遵循6:3:1色彩法则）
```

---

### 6.4 必选变量统一调用规则

```
- {{设计风格变量}}：草原产地原生态风/母婴食品安心风/食欲感舌尖风 等（9选1）
- {{线下门店开关变量}}：有门店/无门店 二选一
- {{产品标签变量}}：用户提供的产品合规标签信息
- {{履约方式变量}}：常温/冷链 二选一
- {{产品名称}}：用户提供的产品官方全称
- {{口味/SKU变量}}：用户提供的产品SKU/口味信息
- {{供货价变量}}：用户提供的B端供货价格（仅供应商产品手册）
- {{零售价变量}}：用户提供的线上零售价格（仅达人选品手册）
```
