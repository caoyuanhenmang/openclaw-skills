# 执行流程规范与自检清单

## 一、视觉生成8步执行流程

```
步骤1：元素提取 - 从产品报告中提取核心卖点、参数、视觉符号
步骤2：场景规划 - 确定画面主题、场景氛围、目标受众
步骤3：布局设计 - 确定构图方式、文案位置、信息层级
步骤4：色调锁定 - 确定主色调、辅助色、点缀色（遵循6:3:1法则）
步骤5：风格适配 - 选择对应的视觉DNA，嵌入提示词
步骤6：细节填充 - 补充产品质感、光影细节、装饰元素
步骤7：提示词生成 - 按照四大模块结构生成完整提示词
步骤8：合规校验 - 检查LOGO位置、文案合规、违禁词规避
```

---

## 二、文案生成8步执行流程

```
步骤1：明确目标 - 确定文案的业务目标、转化目标
步骤2：锁定受众 - 明确目标用户画像、核心痛点
步骤3：选择框架 - 根据场景选择CREATE框架或双轨8模块框架
步骤4：提取卖点 - 从核心报告中提取差异化卖点、核心信息
步骤5：结构设计 - 按照对应渠道的爆款公式设计文案结构
步骤6：调性锁定 - 锁定品牌统一话术、沟通口吻、行文调性
步骤7：文案撰写 - 按照结构撰写文案，确保每个模块对应具体场景
步骤8：合规校验 - 检查违禁词、极限词、虚假宣传表述
```

---

## 三、业务人员极简十问自检清单

非专业人员写提示词前，对照以下10个问题逐一核查，即可规避90%的常见问题：

```
1. 是否明确了AI的专家角色与服务场景？
2. 业务背景与核心目标是否提供了充足的信息？
3. 任务是否拆解成了明确的、可执行的步骤？
4. 是否提供了1-2个优秀示例，明确了"好的标准"？
5. 是否锁定了品牌VI规范/统一话术要求？
6. 是否明确了禁止输出的内容、合规红线与负面约束？
7. 输出格式是否明确，能否直接粘贴使用？
8. 是否限定了参考的数据源，防止AI胡编乱造？
9. 是否告知了AI如果信息不足，应该标注【数据缺失】，不得编造？
10. 是否规定了后续修改的迭代规则，避免多轮对话后整体跑偏？
```

## 四、负面提示词库

### 通用负面提示词

```
模糊,变形,畸形,产品主体偏离,杂乱背景,过曝,欠曝,噪点,
多余物体,电商违禁词,绝对化用语,虚假宣传,
与品牌VI不符的颜色,与视觉DNA相悖的元素,
与品类不符的场景/元素,生产日期,联系方式,条形码,二维码,
B端分销相关内容,不按指定规则排版的内容,
随意生成的产品包装,无任何文案的空白设计图,
品牌LOGO,具体门店数量表述,虚构的优惠促销活动内容
```
