# 9大视觉DNA标准化模板

## 风格选择原则

| 产品类型 | 推荐风格 | 核心逻辑 |
|---------|---------|---------|
| 熟食、零食、调味品、速食 | **食欲感舌尖风** | 激发食欲 |
| 滋补品、中药材、养生茶 | **养生滋补国风** | 养生安心感 |
| 高端食品、奢侈品 | **极简高级质感风** | 突出产品本身 |
| 内蒙古特色生鲜、产地直供产品 | **正宗产地原生态风** | 产地溯源信任感 |
| 茶品、文创产品、中式家居 | **新中式禅意风** | 东方禅意氛围感 |
| 国潮品牌、年轻化传统产品 | **国潮新中式风** | 国潮品牌感 |
| 婴幼儿食品、儿童零食、孕产妇食品 | **母婴食品安心风** | 母婴人群安全感 |
| 儿童食品、IP周边、年轻化产品 | **IP卡通可爱风** | IP品牌辨识度与趣味感 |
| 节日礼盒、节庆产品 | **节日氛围感风** | 节日氛围感与送礼属性 |

## 九大风格专属视觉DNA标准化模板

### 风格1：食欲感舌尖风

**适用品类**：熟食、零食、调味品、速食  
**核心逻辑**：激发用户食欲

**【视觉DNA】**：
```
以食品食欲感为核心底层逻辑，
镜头基准采用15°-45°俯视视角（符合人类用餐视觉习惯），
布光基准采用食品专用90°顶光+45°双侧补光，暖调柔光，色温3200K-3500K；
质感基准强调glossy油亮/juicy多汁/crunchy酥脆的原生质感，
突出食材纤维、肌理、饱满度；
画面底层逻辑以产品主体为绝对核心，弱化无关背景，强化食材原生吸引力，
所有视觉元素必须服务于"激发用户食欲"的核心目标。
```

---

### 风格2：养生滋补国风

**适用品类**：滋补品、中药材、养生茶  
**核心逻辑**：养生安心感

**【视觉DNA】**：
```
以中式养生底蕴为核心底层逻辑，
镜头基准采用平视对称视角，
布光基准采用中式窗格漫射柔光+单侧轮廓光，色温4000K-4500K；
质感基准强调温润原生哑光质感，
突出食材本草肌理、天然质感；
画面底层逻辑遵循中式对称美学，融入传统养生文化元素，
弱化商业硬广感，传递"天然、温和、药食同源"的核心调性，
所有视觉元素必须服务于"养生安心感"的核心目标。
```

---

### 风格3：极简高级质感风

**适用品类**：高端食品、奢侈品  
**核心逻辑**：突出产品本身

**【视觉DNA】**：
```
以少即是多的极简美学为核心底层逻辑，
镜头基准采用平视黄金分割视角，
布光基准采用影棚渐变柔光+单侧轮廓光，色温5000K-5500K；
质感基准强调哑光高级质感，
突出产品材质细节、精致做工、原生肌理；
画面底层逻辑以大量留白突出产品主体，拒绝多余元素堆砌，
传递"克制、高级、有品质"的核心调性，
所有视觉元素必须服务于"突出产品本身"的核心目标。
```

突出产品天然纹路、产地原生属性；

```

### 风格5：新中式禅意风

**适用品类**：茶品、文创产品、中式家居  
**核心逻辑**：东方禅意氛围感

**【视觉DNA】**：
```
以东方禅意留白美学为核心底层逻辑，
镜头基准采用非对称平视视角，
布光基准采用自然漫射柔光+侧方轮廓光，色温4500K；
质感基准强调哑光温润质感，
突出产品细腻肌理、天然材质、极简线条；
画面底层逻辑遵循"空、寂、简"的禅意原则，
大量留白，元素极简，
传递"静谧、雅致、空灵"的核心调性，
所有视觉元素必须服务于"东方禅意氛围感"的核心目标。
```

```
