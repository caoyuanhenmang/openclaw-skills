# 全渠道营销文案爆款公式

## 七大渠道专属爆款公式

| 渠道/平台 | 核心爆款公式 | 核心适配场景 |
|---------|------------|------------|
| **小红书** | 痛点场景化开篇 + 情绪价值共鸣 + 真实测评感细节 + 强互动结尾 + 8-12个高流量标签 | 种草笔记、好物测评、避坑指南、场景化营销 |
| **公众号** | 用户痛点引入 + 深度价值输出 + 品牌理念升华 + 明确的CTA行动引导 | 品牌官宣、深度种草、行业洞察、用户故事、活动推广 |
| **短视频口播（抖音/视频号）** | 3秒黄金钩子 + 痛点共鸣 + 卖点场景化拆解 + 福利逼单 + 行动引导 | 带货口播、品牌宣传、干货科普、直播脚本 |
| **电商详情页** | 首屏痛点冲击 + 核心卖点场景化 + 信任背书 + 细节拆解 + 行动逼单 | 淘宝/京东/抖音电商产品详情页、产品介绍文案 |
| **私域社群/朋友圈** | 生活化开篇 + 福利/价值点 + 真实感细节 + 明确行动引导 | 私域转化、社群团购、老客复购、活动通知 |
| **线下宣传单页/门店POP** | 核心利益点爆点 + 产品核心卖点 + 活动规则 + 门店信息 + 行动引导 | 门店地推、宣传单页、终端陈列文案、活动海报文案 |
| **渠道招商文案** | 行业机会 + 品牌实力 + 加盟优势 + 赋能支持 + 合作模式 + 行动引导 | 招商手册、展会宣讲、加盟推广、分销商招募 |

## 提示词资产库分级管理体系

| 资产库等级 | 适用对象 | 内容范围 | 权限规则 |
|----------|---------|---------|---------|
| **V1.0基础库** | 全团队普通员工、门店店长、分销商、一线终端人员 | 通用文案模板、视觉设计模板、终端动销模板、基础合规工具 | 只读权限，可填空式使用，不可修改模板 |
| **V2.0优化库** | 部门负责人、核心运营、提示词工程师 | 经过AB测试验证的高稳定性核心模板、全链路流水线节点模板、营销与分析核心模板 | 编辑权限，可提出优化建议，可使用全模块功能 |
| **V3.0战略库** | 企业管理层、供应链负责人、首席提示词工程师 | 供应链分析模板、战略规划模板、渠道政策制定模板、核心涉密分析模型 | 最高权限，仅限指定人员访问与使用，严格保密 |
