# 提示词工程专家

## 概述

本技能提供专业的提示词工程方法论，帮助用户生成高质量的视觉和文案提示词。支持电商视觉生成、全渠道营销文案、企业级业务场景等多种应用。

---

## 核心工作流程

### 第一步：场景识别与框架选择

**简单场景**（单一任务、单一环节）→ 使用 CREATE框架  
**复杂场景**（多环节、多部门协同、全链路流转）→ 使用 双轨8模块框架  
**视觉生成场景** → 使用 四大模块 + 视觉DNA + 品牌VI参数字典

**详细方法论**：参考 [core_methodology.md](references/core_methodology.md)

---

### 第二步：视觉生成提示词（适用于电商主图、详情页、直通车等）

#### 1. 选择视觉DNA风格

根据产品类型选择对应的视觉DNA风格：

- 熟食、零食、调味品、速食 → **食欲感舌尖风**
- 滋补品、中药材、养生茶 → **养生滋补国风**
- 高端食品、奢侈品 → **极简高级质感风**
- 内蒙古特色生鲜、产地直供产品 → **正宗产地原生态风**
- 茶品、文创产品、中式家居 → **新中式禅意风**
- 国潮品牌、年轻化传统产品 → **国潮新中式风**
- 婴幼儿食品、儿童零食、孕产妇食品 → **母婴食品安心风**
- 儿童食品、IP周边、年轻化产品 → **IP卡通可爱风**
- 节日礼盒、节庆产品 → **节日氛围感风**

**完整9大风格模板**：参考 [visual_dna.md](references/visual_dna.md)

#### 2. 按四大模块构建提示词

**模块1：视觉重心（Visual Focus）**
```
【视觉DNA完整嵌入此处】，杰作，最佳画质，8K超清分辨率，
商业级电商摄影，超写实，高细节，锐化清晰，专业色彩校准，无噪点；
画面第一视觉重心为【产品名称】主体，
产品占画面核心视觉区域，为画面绝对焦点，
全程无透视变形，产品质感表现严格遵循视觉DNA规范。
```

**模块2：色彩心理（Color Psychology）**
```
画面主色调100%匹配【标准产品图】提取的产品主色调，
辅助色与点缀色贴合视觉DNA的色彩规范与产品品类属性，
整体色彩视觉冲击力强，无任何与产品主色调冲突的违和色系。
```

**模块3：排版结构（Layout Structure）**
```
- 左上角：主标题使用【产品名称】，采用【字体风格】，
  副标题引用【核心卖点】；次卖点搭配对应极简图标横向排列。
- 底部：设置与产品主色调呼应的高饱和度深色底条，
  承载行动呼吁引导文案，文案围绕核心购买人群撰写专属购买理由。
- 所有文案、元素不遮挡产品主体，信息层级清晰。
```

**模块4：元素提取（Element Extraction）**
```
- 包装背书：背景中斜向放置产品包装，建立实物联想，
  强化产品品类与产地属性，严格参考【标准产品图】中的包装样式。
- 画面四周零星散落与产品品类、核心产地、原材料强相关的原生辅助元素，
  搭配自然光影动效，增加画面层级感，
  整体构图平衡，商业质感强，产品品类特色鲜明。
```

#### 3. 遵循强制执行规则

**品牌LOGO管控**：
- 所有电商主图全程禁止出现任何品牌LOGO
- 仅详情页首屏KV海报，强制在画面左上角出现1次品牌LOGO

**品牌VI参数字典**：
- 遵循6:3:1色彩法则（主色60% + 辅助色30% + 点缀色10%）
- 品牌色必须100%匹配品牌方提供的VI规范

**文案内容合规**：
- 所有文案必须100%来自提供的核心报告
- 绝对禁止虚构的优惠促销活动、福利政策、价格折扣相关内容

**详细规则**：参考 [core_methodology.md](references/core_methodology.md)

#### 4. 合规校验

**必查项**：
- LOGO位置是否符合规定？
- 文案是否包含禁用词？
- 是否有虚构的促销内容？
- 色彩是否符合品牌VI规范？

**完整禁用词库**：参考 [banned_words.md](references/banned_words.md)

### 第三步：文案生成提示词（适用于小红书、公众号、短视频等）

#### 1. 选择渠道爆款公式

根据投放渠道选择对应的爆款公式：

- **小红书**：痛点场景化开篇 + 情绪价值共鸣 + 真实测评感细节 + 强互动结尾 + 8-12个高流量标签
- **公众号**：用户痛点引入 + 深度价值输出 + 品牌理念升华 + 明确的CTA行动引导
- **短视频口播**：3秒黄金钩子 + 痛点共鸣 + 卖点场景化拆解 + 福利逼单 + 行动引导
- **电商详情页**：首屏痛点冲击 + 核心卖点场景化 + 信任背书 + 细节拆解 + 行动逼单
- **私域社群/朋友圈**：生活化开篇 + 福利/价值点 + 真实感细节 + 明确行动引导
- **线下宣传单页/门店POP**：核心利益点爆点 + 产品核心卖点 + 活动规则 + 门店信息 + 行动引导
- **渠道招商文案**：行业机会 + 品牌实力 + 加盟优势 + 赋能支持 + 合作模式 + 行动引导

**完整7大渠道公式**：参考 [formulas.md](references/formulas.md)

#### 2. 按执行流程生成文案

**文案生成8步执行流程**：
```
步骤1：明确目标 - 确定文案的业务目标、转化目标
步骤2：锁定受众 - 明确目标用户画像、核心痛点
步骤3：选择框架 - 根据场景选择CREATE框架或双轨8模块框架
步骤4：提取卖点 - 从核心报告中提取差异化卖点、核心信息
步骤5：结构设计 - 按照对应渠道的爆款公式设计文案结构
步骤6：调性锁定 - 锁定品牌统一话术、沟通口吻、行文调性
步骤7：文案撰写 - 按照结构撰写文案，确保每个模块对应具体场景
步骤8：合规校验 - 检查违禁词、极限词、虚假宣传表述
```

**详细执行流程**：参考 [execution_flow.md](references/execution_flow.md)

#### 3. 合规校验

**必查项**：
- 是否包含广告法禁用词？（绝对化用语、极限词等）
- 是否包含医疗暗示词？
- 是否包含虚假承诺？
- 是否包含权威背书违规词？

**完整禁用词库**：参考 [banned_words.md](references/banned_words.md)

## 快速使用指南

### 场景1：生成电商主图提示词

**用户输入示例**：
```
产品：蒙浓无蔗糖奶贝
产品类型：内蒙古特色乳制品
品牌VI：奶皮白为主色调
```

**AI执行步骤**：
1. 识别产品类型 → 内蒙古特色乳制品 → 选择「正宗产地原生态风」
2. 读取视觉DNA模板 → [visual_dna.md](references/visual_dna.md)
3. 按四大模块构建提示词 → 视觉重心 + 色彩心理 + 排版结构 + 元素提取
4. 遵循强制规则 → 品牌LOGO管控 + 文案合规 + 品牌VI参数
5. 合规校验 → 检查禁用词

**输出**：完整的电商主图提示词

---

### 场景2：生成小红书种草笔记提示词

**用户输入示例**：
```
产品：儿童零食
渠道：小红书
目标：种草笔记
```

**AI执行步骤**：
1. 识别渠道 → 小红书 → 选择小红书爆款公式
2. 读取爆款公式 → [formulas.md](references/formulas.md)
3. 按公式设计结构 → 痛点场景化开篇 + 情绪价值共鸣 + 真实测评感细节 + 强互动结尾 + 8-12个高流量标签
4. 提取卖点 → 从用户提供的核心报告中提取
5. 合规校验 → 检查禁用词

**输出**：完整的小红书种草笔记提示词

## 使用建议

1. **先识别场景**：判断是视觉生成还是文案生成，简单场景还是复杂场景
2. **再选择工具**：根据场景选择对应的框架、公式、视觉DNA
3. **后生成提示词**：按照执行流程逐步构建提示词
4. **最后合规校验**：确保提示词符合品牌规范和法律法规

**核心原则**：输出即可用，合规是底线。
