## 一、赛道选择模块

### 核心公式

```
优质赛道 = 长度(可持续性) × 宽度(市场规模) × 拥挤度(竞争强度)
```

### 1.1 三维评估模型

**长度评估**（30%权重）：
- 政策-社会周期耦合度（10分）
- 需求刚性时效锚（10分）
- 技术路径稳定锚（10分）

**宽度评估**（40%权重）：
- 用户规模与渗透率（16分）
- 场景延展性（12分）
- 产业链深度（12分）

**拥挤度评估**（30%权重）：
- 现有玩家格局（12分）
- 行业壁垒（9分）
- 盈利模式同质化（9分）

**决策矩阵**：
- 总分≥80分：S级赛道，优先进入
- 总分60-79分：A级赛道，需差异化优势
- 总分40-59分：B级赛道，谨慎进入
- 总分<40分：C级赛道，建议放弃

### 1.2 三大导向模型

**核心公式**：
```
优质赛道 = 趋势红利期 ⋂ 真实刚需 ⋂ 能力匹配圈
```

**趋势导向评估**：
- 政策趋势：三阶预判法（顶层导向→地方细则→执行周期）
- 技术趋势：Gartner曲线（避免泡沫顶点，选复苏斜坡期）
- 人口消费趋势：客群规模增速>10%、客单价增速>8%、渗透率<20%

**需求导向评估**：
- 需求频次：1-5分（日频5分→年频1分）
- 需求刚性：1-5分（绝对刚性5分→无刚性1分）
- 支付意愿：1-5分（溢价30%以上5分→无付费意愿1分）
- 赛道等级：S级(12-15分)、A级(9-11分)、B级(6-8分)、C级(≤5分)

**能力导向评估**：
- 资源优势：供应链/渠道/品牌/资金四类核心资源
- 能力优势：研发/运营/产品/营销四类核心能力
- 认知优势：用户隐性需求/行业隐规则/产业链利益分配
- 匹配度要求：核心优势与赛道KSF匹配度>70%方可进入

**完整评估手册**：见 [references/track-selection.md](references/track-selection.md)

## 二、营销定位模块

### 2.1 STP营销定位模型

**核心流程**：
```
市场细分(S) → 目标市场选择(T) → 市场定位(P)
```

**市场细分四维度**：
- 地理细分：区域、城市等级、气候
- 人口细分：年龄、性别、收入、职业
- 心理细分：生活方式、价值观、个性
- 行为细分：购买频率、忠诚度、使用场景

**目标市场选择评估**：
- 市场规模：潜在用户数×转化率×客单价
- 增长潜力：年复合增长率、渗透率
- 竞争强度：头部集中度、进入壁垒
- 资源匹配：企业资源与市场需求匹配度

**市场定位策略**：
- 差异化定位：独特价值主张
- 成本领先定位：性价比优势
- 聚焦定位：细分市场专家

### 2.2 AIDAL漏斗转化模型

**核心流程**：
```
认知(A) → 兴趣(I) → 渴望(D) → 行动(A) → 忠诚(L)
```

**各阶段关键指标**：
| 阶段 | 关键指标 | 优化方向 |
|------|---------|---------|
| 认知 | 曝光量、触达率 | 扩大渠道覆盖、提升品牌知名度 |
| 兴趣 | 点击率、停留时长 | 优化内容质量、提升用户体验 |
| 渴望 | 收藏率、加购率 | 强化价值主张、建立信任背书 |
| 行动 | 转化率、客单价 | 简化购买流程、提供优惠激励 |
| 忠诚 | 复购率、转介绍率 | 提升服务质量、建立会员体系 |

### 2.3 价值主张画布

**核心要素**：
- **客户任务**：用户需要完成的核心任务
- **痛点**：用户在完成任务时遇到的障碍
- **收益**：用户期望获得的价值和结果
- **产品服务**：提供的解决方案
- **痛点缓解**：如何解决用户痛点
- **收益创造**：如何创造用户价值

**完整营销手册**：见 [references/marketing-positioning.md](references/marketing-positioning.md)

## 三、品牌战略模块

### 3.1 品牌认知升级三阶段模型

**核心流程**：
```
认知建立期 → 认知强化期 → 认知变现期
```

**各阶段核心动作**：

| 阶段 | 核心目标 | 关键动作 | 评估指标 |
|------|---------|---------|---------|
| 认知建立期 | 让用户知道你是谁 | 定位明确、触达精准、记忆深刻 | 品牌知名度、认知度 |
| 认知强化期 | 让用户信任你 | 持续曝光、信任背书、情感连接 | 品牌美誉度、信任度 |
| 认知变现期 | 让用户选择你 | 溢价能力、复购忠诚、转介绍 | 品牌忠诚度、NPS |

### 3.2 用户心智占位策略

**心智定位原则**：
- **第一原则**：成为品类第一或创造新品类
- **差异化原则**：提供独特价值主张
- **聚焦原则**：在用户心智中占据一个词

**心智占位方法**：
- 抢占空位：发现市场空白，快速占位
- 关联定位：与强势品牌建立关联
- 重新定位：重新定义竞争对手

### 3.3 品牌资产构建

**品牌资产五维度**：
- 品牌知名度：用户知道品牌的程度
- 品牌认知度：用户对品牌的理解程度
- 品牌美誉度：用户对品牌的好感程度
- 品牌忠诚度：用户重复购买的意愿
- 品牌联想：用户对品牌的印象和联想

**完整品牌手册**：见 [references/brand-strategy.md](references/brand-strategy.md)

## 四、商业模式模块

### 4.1 商业模式画布九要素

**核心要素框架**：

```
┌─────────────┬─────────────┬─────────────┬─────────────┬─────────────┐
│  关键合作    │  关键业务    │  价值主张    │  客户关系    │  客户细分    │
│             │             │             │             │             │
│             ├─────────────┤             ├─────────────┤             │
│             │  核心资源    │             │  渠道通路    │             │
├─────────────┴─────────────┴─────────────┴─────────────┴─────────────┤
│                          成本结构                                      │
├───────────────────────────────────────────────────────────────────────┤
│                          收入来源                                      │
└───────────────────────────────────────────────────────────────────────┘
```

**各要素定义**：
1. **客户细分**：目标用户群体
2. **价值主张**：为用户提供的独特价值
3. **渠道通路**：触达用户的方式
4. **客户关系**：与用户的互动方式
5. **收入来源**：盈利模式
6. **核心资源**：关键资产和能力
7. **关键业务**：核心运营活动
8. **重要合作**：关键合作伙伴
9. **成本结构**：主要成本构成

### 4.2 商业模式设计原则

**设计原则**：
- 可持续性：能够长期稳定盈利
- 可扩展性：具备规模化增长潜力
- 差异化：与竞争对手形成区隔
- 用户价值：真正解决用户痛点

**完整商业手册**：见 [references/business-model.md](references/business-model.md)

## 五、实战应用场景

### 场景1：产品定位分析

**应用流程**：
1. 使用赛道选择模型评估产品所在赛道
2. 使用STP模型确定目标用户和定位
3. 使用价值主张画布验证产品价值
4. 使用商业模式画布设计盈利模式

**输出物**：
- 产品定位报告
- 目标用户画像
- 价值主张陈述
- 商业模式设计

### 场景2：项目可行性评估

**应用流程**：
1. 使用三维评估模型评估项目赛道
2. 使用能力导向模型评估企业匹配度
3. 使用商业模式画布评估盈利可行性
4. 使用AIDAL漏斗评估市场潜力

**输出物**：
- 项目可行性报告
- 风险评估矩阵
- 投资回报预测
- 关键成功因素

### 场景3：品牌战略规划

**应用流程**：
1. 使用品牌认知三阶段模型规划品牌发展路径
2. 使用心智占位策略确定品牌定位
3. 使用品牌资产五维度设计品牌建设方案
4. 使用STP模型确定品牌传播策略

**输出物**：
- 品牌定位报告
- 品牌建设方案
- 品牌传播策略
- 品牌资产评估

### 场景4：市场进入决策

**应用流程**：
1. 使用趋势导向模型评估市场机会
2. 使用需求导向模型验证市场真实性
3. 使用拥挤度评估模型判断竞争格局
4. 使用能力导向模型评估进入可行性

**输出物**：
- 市场机会评估报告
- 竞争格局分析
- 进入策略建议
- 资源配置方案

## 六、使用指南

### 快速决策流程

**第一步：明确问题**
- 是产品定位、项目评估还是市场进入？
- 需要战略决策、营销定位还是品牌规划？

**第二步：选择模型**
- 战略决策 → 赛道选择模型
- 营销定位 → STP/AIDAL模型
- 品牌规划 → 品牌认知三阶段模型
- 商业模式 → 商业模式画布

**第三步：量化评估**
- 使用评分卡进行量化打分
- 对照决策矩阵得出结论
- 识别关键风险和机会

**第四步：输出方案**
- 形成分析报告
- 提出行动建议
- 制定执行计划

### 关键注意事项

1. **数据驱动**：评估必须基于真实数据，避免主观判断
2. **多维验证**：重要决策需多个模型交叉验证
3. **动态调整**：市场环境变化需及时调整评估
4. **资源匹配**：战略决策需考虑企业实际资源能力
