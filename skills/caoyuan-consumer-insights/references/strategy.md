## 三、战略升级方向

### 定位升级
```
旧：卖内蒙古特产
新：卖内蒙古健康生活方式
```

### 场景升级
每款产品必须绑定具体消费场景：
- **佐餐**：火锅/烧烤/日常配餐
- **解压**：办公室零食/深夜治愈
- **养生**：日常滋补/季节调理
- **送礼**：节日/探望/商务
- **社交**：露营/聚会/野餐

### 渠道匹配
| 渠道 | 匹配产品 | 优先级 |
|------|---------|--------|
| 抖音电商 | 第一阶段全部产品 | ★★★★★ |
| 小红书 | 肉苁蓉/黄芪/滋补线 | ★★★★★ |
| 美团闪购 | 云连锁门店即时品类 | ★★★★ |
| 品牌旗舰店 | 全品类+礼盒 | ★★★★ |
| 社区团购 | 生鲜肉类+奶制品 | ★★★ |

## 五、谨慎品类

| 品类 | 风险点 | 建议 |
|------|--------|------|
| 高度白酒 | Z世代饮酒去烈度化 | 谨慎，除非走高端礼品路线 |
| 纯初加工原料 | "卖原料"已死 | 必须升级为"卖方案"（预包装+品牌化） |
| 冷链重度依赖品 | 冷链成本高企 | 优先开发常温化/半常温化版本 |

---

## 六、产品开发决策检查清单

每款新产品立项前，必须通过以下6项检查：

- [ ] **趋势验证**：是否与八大确定性趋势中的至少1项吻合？
- [ ] **配料表检查**：是否做到了"清洁标签"？配料表是否足够短？
- [ ] **场景绑定**：是否明确绑定了至少1个具体消费场景？
- [ ] **价格带定位**：是否在引流/利润/复购三层中有明确定位？
- [ ] **渠道匹配**：是否确定了首发渠道（抖音/小红书/闪购/旗舰店）？
- [ ] **情绪价值**：包装和体验是否具备"出片率"和社交分享属性？
