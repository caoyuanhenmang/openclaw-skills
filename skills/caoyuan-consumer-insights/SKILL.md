## 核心方法论框架

### 消费范式三级跳

```
性价比(1.0) → 情价比(2.0) → 心价比(3.0)
```

当前中国消费市场处于2.0向3.0过渡期：
- **情绪价值**：情绪消费市场1.4万亿（+29%），56.3%消费者选择"情价比"
- **健康价值**：54.2%消费者首选配料表干净，药食同源线上1266亿（+28.9%）
- **文化认同**："全人消费"取代物质占有，国潮2.0进入实力主导期

### 产品开发底层逻辑

```
配方做减法 × 体验做加法 × 场景做乘法
```

## 快速速查：产品开发六大法则

1. **清洁标签法则**：零添加/短配料表是底线，第三方认证构筑品牌资产
2. **药食同源三维重构**：传统内核 + 科学复配 + 场景降维
3. **价格带矩阵**：试用装(扫清障碍) → 正装(贡献利润) → 大包装(锁定复购)
4. **场景化设计**：每款产品绑定具体消费微场景（早餐/上班/下午茶/聚餐/睡前）
5. **情绪价值注入**：功能价值 + 情绪价值 + 社交货币 = 溢价空间
6. **"出片率"思维**：产品设计考虑消费者的内容创作和社交分享需求
