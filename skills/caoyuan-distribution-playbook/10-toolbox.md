## 一、核心公式（8条，去重后）

### 1. 经销商竞争力公式（《成功密码》）
```
经销商竞争力 = 营销力 × 数字化能力 × 供应链效率
```

### 2. 深度分销效益·三元叠增（《成功密码》）
```
深度分销效益 = 网点数量 × 产品品项 × 消费群体
```

### 3. 单店产出公式（《成功密码》）
```
单店产出 = 陈列质量 × 拜访频率 × 服务深度
```

### 4. 投资回报率（《这样做才赚钱》）
```
投资回报率 = 营业利润 ÷ 运营资金
```

### 5. 经销商价值公式（《还能做多久》）
```
经销商价值 = 成本优势 × 社会资源 × 信用资产 × 服务深度
```

### 6. 经销商盈利公式（《周转周赚》）
```
经销商盈利 = 毛利高 × 费用低 × 周转快
```

### 7. 销售额四因素（《周转周赚》）
```
销售额 = 网点覆盖 × 品类宽度 × 客单价 × 复购率
```

### 8. 企业价值公式（《引爆招商》）
```
企业价值 = 渠道数据 × 用户数据 × 赋能体系
```

## 二、核心模型/框架

### 1. ABCD四级经销商评估体系
- 来源：《窜货管理》
- 四维度：人脉资源 × 资金实力 × 年订货量 × 营销团队
- 详见：`02-dealer-selection.md`

### 2. 赫茨伯格双因素激励模型
- 来源：《激励》
- 保健因素：返利/控价/区域保护/防窜（没有会不满）
- 激励因素：竞赛/荣誉/参与/培训（有了才积极）
- 详见：`06-incentive.md`

### 3. 马斯洛需求映射
- 来源：《激励》
- 生存→安全→社交→尊重→自我实现
- 初期给钱，中期给面子，成熟期给参与权
- 详见：`06-incentive.md`

### 4. 融招养三位一体
- 来源：《引爆招商》
- 融商（招商前自我诊断）→招商（九大引爆+三网获客）→养商（复盘+赋能+裂变）
- 详见：`07-nurture-channel.md`

### 5. 经销商生意四阶段匹配法
- 来源：《这样做才赚钱》
- 创业期→成长期→成熟期→衰退期，不同阶段不同策略
- 详见：`02-dealer-selection.md`

### 6. 产品三分类模型
- 来源：《这样做才赚钱》
- 流量品（引流）+ 利润品（赚钱）+ 种子品（培育）
- 详见：`03-pricing-rebate.md`

### 7. 渠道细分法（斯莱沃斯基法）
- 来源：《周转周赚》
- 6大类→22中类→45小类
- 详见：`07-nurture-channel.md`

### 8. 客户心理六问模型
- 来源：《招商高手》
- 你是谁→产品好不好→能赚多少→风险大不大→别人怎样→现在签有什么好处
- 详见：`05-roadshow-sop.md`

### 9. 九大引爆策略
- 来源：《引爆招商》
- 引爆产品/服务/品牌/模式/团队/会议/广告/平台/系统
- 详见：`05-roadshow-sop.md`

### 10. 防窜货三位一体
- 来源：《窜货管理》
- 人防（督察部）+ 技防（一物一码）+ 制防（合同+保证金）
- 详见：`04-anti-diversion.md`
