# 💰 返利与价格体系设计

> 7/9本书都在警告返利设计——这是招商最容易踩的坑。

---

## 一、四级价格体系（来源：《窜货管理》）

```
出厂价 → 经销价 → 二批价 → 零售指导价
```

### 设计原则
- 每一级价差必须明确，不得模糊
- 经销商毛利空间≥15%（食品行业底线）
- 任何层级不得低于下一级价格售卖，违反视为窜货
- 线上线下统一指导价，避免渠道冲突

### 定价参考公式
```
经销价 = 出厂价 × (1 + 经销商毛利率)
二批价 = 经销价 × (1 + 二批毛利率)
零售价 = 二批价 × (1 + 零售毛利率)
```

## 二、组合返利机制（7本书共识）

### 六种返利类型（来源：《窜货管理》）

| 返利类型 | 兑现周期 | 挂钩指标 | 建议比例 |
|---------|---------|---------|---------|
| 月度现返 | 当月 | 进货额 | 1-2% |
| 季度过程返 | 季度末 | 铺市率/陈列/动销达成 | 0.5-1% |
| 年度达标返 | 年末 | 年度目标完成率 | 1-2% |
| 专卖返 | 年末 | 独家经营同品类 | 0.5-1% |
| 新品推广返 | 首批 | 新品进货 | 额外1-2% |
| 淡旺季调节返 | 即时 | 淡季进货 | 临时设定 |

### 返利设计7步法（来源：《激励》）

```
Step1：明确分销目标（铺市率/销量/新品推广）
  ↓
Step2：调研经销商真实需求（4种途径）
  ↓
Step3：匹配需求设计激励方案
  ↓
Step4：设置返利（按时间/对象/内容/形式）
  ↓
Step5：建立厂商共赢委员会
  ↓
Step6：实施培训激励
  ↓
Step7：评估与调整
```

### 4种需求调研途径
1. 厂家直接调研（业务员日常沟通）
2. 第三方调研（解决厂商矛盾盲区）
3. 厂商共赢委员会（让经销商参与决策）
4. 日常沟通反馈

## 三、返利红线（绝对不能触碰）

1. **返利总额≤毛利的30%**——超过必窜货（Z纸业案例血的教训）
2. **返利兑现周期≤3个月**——拖太久经销商失去信任
3. **禁止纯销量挂钩**——必须与过程指标（铺市/陈列/合规）挂钩
4. **禁止年终一次性大返**——这是定时炸弹
5. **当季窜货=取消当季所有返利**——返利与防窜合规必须挂钩

## 四、产品三分类与差异化返利（来源：《这样做才赚钱》）

| 产品类型 | 定位 | 毛利 | 周转 | 返利策略 |
|---------|------|------|------|---------|
| 流量品 | 引流，打开市场 | 低 | 快 | 低返利，重铺市率考核 |
| 利润品 | 核心盈利来源 | 高 | 中 | 中等返利，重陈列和动销 |
| 种子品 | 未来潜力股 | 中高 | 慢 | 高推广返，重试销和反馈 |

## 五、经销商算账表模板（来源：《这样做才赚钱》）

```
投资回报率 = 营业利润 ÷ 运营资金

其中：
  营业利润 = 销售额 × 毛利率 - 运营费用（仓储+配送+人力+损耗）
  运营资金 = 首批打款 + 保证金 + 月均库存占用 + 应收账款占用

示例：
  月销售额：10万元
  毛利率：20%
  月毛利：2万元
  月运营费用：0.8万元
  月营业利润：1.2万元
  运营资金：15万元（首批5万+保证金2万+库存5万+应收3万）
  年投资回报率：1.2×12÷15 = 96%
  回本周期：约12.5个月
```

## 六、保证金与首批打款

### 保证金设计
- 防窜货保证金：首批货款的5-10%
- 合同期内无窜货，到期全额退还
- 窜货扣款阶梯：首次扣30% → 二次扣100% → 三次解约

### 首批打款设计
- 根据区域市场容量和终端数量核算
- 不宜过高（压货伤害经销商现金流）
- 不宜过低（经销商没动力推）
- 建议：首批进货量=预估月销量×2-3个月
