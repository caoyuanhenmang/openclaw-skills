# 🎤 招商会SOP

> 招商会是集中转化的核心场景——必须精心策划，不能只是吃饭发传单。

---

## 一、招商会全流程六步法（来源：《招商高手》）

### Step1：定主题
- 主题必须一句话说清价值主张
- 示例："草原很忙·内蒙古健康特产城市合伙人招募会"
- 主题要传递三个信息：你是谁、你卖什么、经销商能得到什么

### Step2：筛客户
- 客户邀约六步流程（来源：《招商宝典》）：
  1. 收集信息，列出潜在客户名单（展会/协会/同行推荐/终端反查）
  2. 分析客户信息并分类分级（A/B/C级意向度）
  3. 设计招商DM单页（一页纸说清项目价值）
  4. 设计招商邀请函（正式感+稀缺性）
  5. 借势营销引爆关注（搭行业展会/热点事件）
  6. 电话邀约+上门拜访（A级必上门，B级电话+微信，C级群发）

### Step3：设计演讲
- 招商项目介绍四步法（来源：《招商宝典》）：
  1. **盈利预测**：明确利润总额和回本周期
  2. **盈利模式**：匹配对应模式类型
  3. **SWOT分析**：主动暴露劣势建立信任
  4. **卖点提炼**：提炼差异化卖点

- 演讲结构建议：
  ```
  开场（5分钟）：创始人故事+品牌愿景
  痛点（10分钟）：行业问题+经销商痛点
  方案（20分钟）：产品展示+商业模式+利润测算
  证据（10分钟）：样板市场数据+经销商见证
  政策（15分钟）：招商政策详解+现场优惠
  答疑（10分钟）：现场提问互动
  ```

### Step4：制定现场优惠
- 限时优惠：现场签约享额外返利__%
- 限量优惠：前__名签约赠品牌专属货架
- 限场优惠：本场专属政策，会后不再提供
- ⚠️ 优惠不能过于激进，避免"割韭菜"嫌疑

### Step5：唱单环节
- 每签约一位，主持人现场播报（营造氛围）
- 签约区与洽谈区分开
- 安排2-3位"种子客户"提前确认意向，带动签约节奏

### Step6：会后跟踪
- 48小时内必须回访所有参会者
- A级意向：24小时内上门拜访
- B级意向：48小时内电话跟进
- C级意向：一周内微信跟进
- 所有参会者加微信，纳入私域持续运营

## 二、九大引爆策略（来源：《引爆招商》）

| 引爆点 | 具体方式 | 草原很忙适配 |
|-------|---------|------------|
| 引爆产品 | 打造明星单品 | 武川莜面/牛肉干 |
| 引爆服务 | 超出预期的赋能 | 数字化工具+培训体系 |
| 引爆品牌 | 品牌故事+IP | 高老师创业故事 |
| 引爆模式 | 创新合作模式 | "卖商机"而非"卖产品" |
| 引爆团队 | 专业团队展示 | 展示龙虾团队实力 |
| 引爆会议 | 招商会现场氛围 | 唱单+限时优惠 |
| 引爆广告 | 多渠道宣传 | 抖音+朋友圈+行业媒体 |
| 引爆平台 | 借势大平台 | 搭食品展会/博览会 |
| 引爆系统 | 数字化系统展示 | 展示经销商管理系统 |

## 四、招商会谈判策略（来源：《招商宝典》）

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| 先大后小让步 | 第一次让步幅度最大，后续递减 | 价格谈判 |
| 钳子策略 | "你的条件还不够"，让对方先出底牌 | 对方报价时 |
| 白脸+黑脸 | 一人唱红脸一人唱白脸 | 团队谈判 |
| 捕捉成交信号 | 对方问细节=有意向，立即推进 | 全程观察 |
| 稀缺性营造 | "这个区域只剩最后一个名额" | 促成签约 |

## 五、客户心理六问模型（来源：《招商高手》）

经销商决策过程中会经历六个心理门槛：

```
1. 你是谁？→ 品牌故事+创始人IP解决
2. 产品好不好？→ 产品体验+品质背书解决
3. 能赚多少钱？→ 算账表+利润测算解决
4. 风险大不大？→ 试销期+保证金退还解决
5. 别人做得怎样？→ 样板市场+经销商见证解决
6. 现在签有什么好处？→ 限时优惠+稀缺性解决
```

> 💡 招商演讲必须按顺序回答这六个问题，少回答任何一个都会丢客户。
