# ⚠️ 踩坑清单

> 5大高频踩坑 + 警示红线。每次重大招商决策前必查。

---

## 一、5大高频踩坑（交叉验证排名）

### 踩坑1：返利过高/过激（4/9本提及）

**典型案例**：
- Z纸业：返利完全透明→大户精准计算利润空间→集中进货后倾销→价格崩溃→品牌受损
- 《招商高手》：某品牌高额返利+过低加盟费→经销商只为套返利，不做终端→3个月后集体退出

**教训**：
- 食品行业毛利15-25%，返利总额不能超过毛利的30%
- 返利不能完全透明，建议"半透明"——基础返利公开，额外奖励暗返
- 返利必须与过程指标挂钩，不能只挂销量

**防范措施**：
- [ ] 返利总额是否≤毛利的30%？
- [ ] 是否有月度过程返利？（而非只有年终返）
- [ ] 返利是否与铺市/陈列/动销/防窜合规挂钩？
- [ ] 是否有返利上限封顶机制？

---

### 踩坑2：单一渠道依赖（4/9本提及）

**典型案例**：
- 某经销商只做线下传统渠道→社区团购/即时零售崛起→销量腰斩
- 某经销商只代理一个品牌→厂家换人→整个生意崩盘

**教训**：
- 只做线下=等死
- 单一厂家依赖=被切市场的风险
- 一个模式不能应对所有阶段

**防范措施**：
- [ ] 经销商是否至少覆盖3种渠道类型？
- [ ] 我方产品在经销商总业务占比是否≤30%？
- [ ] 是否有线上渠道规划（即时零售/私域/社区团购）？

---

### 踩坑3：重招轻养（3/9本提及）

**典型案例**：
- 《招商宝典》：某连锁品牌签约200家加盟商→签约后无管理无支持→半年内关店60%
- 《激励》：厂家一味要求提销量→不给终端支持→经销商反感→分道扬镳

**教训**：
- 招一个客户的成本是养一个客户的5-10倍
- 签约后放任=最大的浪费
- 经销商流失的核心原因不是利润低，是"感觉不被重视"

**防范措施**：
- [ ] 签约后48小时内是否有回访机制？
- [ ] 是否有专人负责养商？（养商专员）
- [ ] 是否有月度复盘会制度？
- [ ] 是否有季度培训计划？
- [ ] 经销商满意度是否纳入团队KPI？

---

### 踩坑4：管理混乱（3/9本提及）

**典型案例**：
- 《还能做多久》：经销商凭感觉做生意，不计后台成本→账面赚钱实际亏钱
- 《成功密码》：三五人却投资自建技术平台→资金链断裂
- 应收账款失控→坏账拖垮现金流

**教训**：
- 不帮经销商做管理升级，只催销量=饮鸩止渴
- 经销商的管理水平决定了合作天花板
- 应收账款是隐形杀手

**防范措施**：
- [ ] 是否有经销商应收账款预警机制？（超30天自动提醒）
- [ ] 是否提供管理培训（财务/库存/团队）？
- [ ] 是否帮经销商建立基本的数据报表体系？
- [ ] 是否有定期巡店制度？

---

### 踩坑5：盲目转型（2/9本提及）

**典型案例**：
- 《成功密码》：三五人投资自建技术平台→技术不是核心能力→血本无归
- 《还能做多久》：合伙人制快速消退→"合伙人制是管理水平的倒退"

**教训**：
- 不鼓励经销商自建平台，提供我方工具即可
- 初期不要急着给经销商股权
- 转型要"先练内功再上系统"

**防范措施**：
- [ ] 是否要求经销商自建系统？（应提供我方工具）
- [ ] 是否过早讨论股权/合伙人？（先用返利绑定）
- [ ] 数字化是否按正确顺序推进？（先访单→再订货→再数据）

## 二、观点分歧区（需根据实际情况取舍）

| 议题 | 正方 | 反方 | 建议 |
|------|------|------|------|
| 返利透明度 | 透明有利于预期管理 | 过度透明→大户套利 | 半透明：基础公开，额外暗返 |
| 经销商数量 | 区域独家 | 多经销商竞争 | 0→1阶段先独家，跑通再开第二家 |
| 转型优先级 | 先管理升级 | 先招商造血 | 两条腿同时走，但管理底线不能破 |
| 深度分销vs扁平化 | 深度分销是王道 | 扁平化是趋势 | 核心城市做深度，其他区域先扁平覆盖 |
| 老板IP | 是第一杠杆 | 其他8本未强调 | 创始人有基础的值得重点投入 |

## 三、重大决策前必查清单

每次做以下决策前，必须逐条检查：

### 签约新经销商前
- [ ] ABCD四级评估是否达到B级以上？
- [ ] 是否实地考察过仓库/团队/终端？
- [ ] 合同是否包含防窜货+保证金条款？
- [ ] 是否明确试销期（3个月或三批进货量）？

### 调整返利政策前
- [ ] 返利总额是否≤毛利的30%？
- [ ] 是否征求了共赢委员会意见？
- [ ] 是否做过经销商满意度调研？
- [ ] 新政策是否会导致窜货风险？

### 开拓新区域前
- [ ] 是否有样板市场数据支撑？
- [ ] 是否明确了区域边界（含线上渠道）？
- [ ] 是否有足够的管理团队覆盖？
- [ ] 是否做了投入产出测算？

### 办招商会前
- [ ] 是否完成了客户邀约六步流程？
- [ ] 是否准备了经销商算账表？
- [ ] 是否有样板市场/经销商见证？
- [ ] 现场优惠是否控制在合理范围内？
