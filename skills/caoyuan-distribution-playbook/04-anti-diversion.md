# 🛡️ 防窜货体系

> 窜货是渠道第一杀手。5/9本书反复验证这一点。

---

## 一、窜货的本质与分类

### 窜货三类型（来源：《窜货管理》）

| 类型 | 定义 | 危害等级 | 处理方式 |
|------|------|---------|---------|
| 恶性窜货 | 故意跨区低价倾销 | ★★★★★ | 严厉处罚直至解约 |
| 自然窜货 | 边界模糊区域的自然流通 | ★★☆☆☆ | 明确边界，教育为主 |
| 良性窜货 | 空白市场策略性铺货 | ★☆☆☆☆ | 可暂时允许，后续搭建正式体系 |

> 💡 TS啤酒案例：在空白市场策略性允许良性窜货，快速起量后再搭建正式经销体系。

## 二、人防+技防+制防三位一体（来源：《窜货管理》）

### 人防——市场督察部

| 项目 | 标准 |
|------|------|
| 组织架构 | 独立于销售部门，直属总经理 |
| 人员配比 | 督察员：经销商 = 1:5 ~ 1:15 |
| 巡查频率 | 核心区域每周1次，普通区域每月2次 |
| 巡查内容 | 终端价格、货源追溯、物流单据 |
| 激励机制 | 窜货举报奖励（经销商/业务员/消费者均可举报） |

### 技防——数字化追踪

| 手段 | 说明 |
|------|------|
| 一物一码 | 每箱/每袋唯一追溯码，扫码即知出货区域 |
| 物流追踪 | 发货单与经销商绑定，可追溯货物流向 |
| 终端扫码 | 终端收货扫码确认，异常自动预警 |
| 电商监控 | 监控抖音小店/拼多多/淘宝跨区发货 |

### 制防——制度约束

| 制度 | 内容 |
|------|------|
| 合同条款 | 明确窜货定义、处罚标准、举证方式 |
| 保证金 | 首批货款5-10%作为防窜保证金 |
| 处罚阶梯 | 首次警告+扣30%保证金→二次扣100%→三次解约 |
| 公示制度 | 窜货处理结果向所有经销商公示 |
| 线上约束 | 禁止通过B2B/O2O平台跨区销售 |

## 三、窜货事件处理五步法

```
Step1：发现
  ├─ 途径：经销商投诉、督察巡查、消费者举报、数据异常
  └─ 要求：24小时内启动调查

Step2：取证
  ├─ 购买窜货产品保留实物
  ├─ 拍照/录像留存
  ├─ 扫码追溯出货信息
  └─ 收集物流单据

Step3：认定
  ├─ 确认窜货来源区域
  ├─ 确认窜货数量和金额
  ├─ 确认窜货性质（恶性/自然/良性）
  └─ 形成书面调查报告

Step4：处罚
  ├─ 按合同条款执行
  ├─ 扣除相应保证金
  ├─ 取消当季返利
  └─ 严重者解除合同

Step5：公示
  ├─ 向所有经销商通报处理结果
  ├─ 不公开具体金额，只公开处罚措施
  └─ 起到警示作用
```

## 四、区域划分原则

### 双标准划分法（来源：《窜货管理》）

```
区域边界 = 行政区域 + 自然流通路线
```

- **行政区域**：市/旗/县为基本单位
- **自然流通路线**：按实际物流路线、商圈辐射范围调整
- **两者不一致时**：以自然流通路线为准

### 特殊区域处理
- **交界区域**：明确归属，写入合同附件地图
- **线上渠道**：按发货地址界定区域，不按收货地址
- **即时零售**：按门店所在区域界定

## 五、新型窜货防范（来源：《周转周赚》+《成功密码》）

| 新型窜货 | 表现 | 防范措施 |
|---------|------|---------|
| 电商窜货 | 经销商在拼多多/抖音低价出货 | 合同禁止未授权线上销售 |
| B2B窜货 | 通过零售通/美菜等平台跨区 | 合同明确B2B平台销售范围 |
| 社区团购窜货 | 通过多多买菜/美团优选跨区 | 设定线上最低限价 |
| 代购窜货 | 通过微信代购跨区销售 | 一物一码追踪+举报奖励 |

## 六、合同防窜条款模板要点

合同中必须包含以下条款：
1. 经销区域的精确定义（附地图）
2. 窜货行为的明确定义（含线上渠道）
3. 保证金金额和扣款规则
4. 窜货处罚阶梯
5. 举证方式和调查流程
6. 返利与防窜合规的挂钩机制
7. 经销商配合调查的义务
8. 严重窜货的合同解除条款
